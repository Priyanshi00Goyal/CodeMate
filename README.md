# 💻 CodeMate

> Your AI-powered coding companion for learning, debugging, improving, and practicing code.

CodeMate is a Streamlit-based AI coding assistant designed to help students understand programming concepts, debug code, improve solutions, and practice coding problems.

---

## ✨ Features

### 🧠 Code Explainer

Paste your code and CodeMate provides:

- Beginner-friendly explanation
- Step-by-step breakdown
- Programming concepts used
- Time complexity
- Space complexity

### 🐛 Bug Finder

Find potential problems in your code and understand:

- What went wrong
- Why it happened
- How to fix it
- Corrected code
- Prevention tips

### ✨ Code Improver

Improve your existing code with:

- Better readability
- Cleaner structure
- Maintainability suggestions
- Programming tips

### 📚 Practice Mode

Practice programming with AI-generated challenges.

Choose:

- Topic
- Difficulty

Then submit your solution and receive:

- Score out of 10
- Result
- Feedback
- Improvement suggestions
- Learning tips

### 📊 Progress Dashboard

Track your coding journey with:

- Problems solved
- Average score
- Best score
- Topics practiced
- Score history
- Difficulty distribution
- Practice history
